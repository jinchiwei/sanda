# sanda (散打)

A terminal typing trainer that finds what actually slows you down and drills it.

Monkeytype-style tests (time, words, quotes with sources) plus keystroke-level analysis: per-transition timing, Shift / punctuation / number costs, adaptive drills, an overspeed pacer and spaced repetition. Themes include Monkeytype's presets.

> Status: early design. See [docs/spec.md](docs/spec.md).
